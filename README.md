# SilverNest

## Project Description

SilverNest is a web application designed to connect seniors and family caregivers with local volunteers who provide non-medical assistance.The platform aims to support seniors in their daily activities by allowing them to request help with tasks such as grocery shopping, pharmacy pickups, light household chores, and accompanied walks.Family caregivers can monitor assistance requests, while volunteers can browse and accept available tasks.

## Technologies and Frameworks

- React.js – Front-end development
- Vite – Development and build tool
- JavaScript – Application functionality
- HTML and CSS – Page structure and styling
- React Router – Navigation between pages
- Node.js and npm – Development environment and package management

## Setup and Installation

### Prerequisites

Make sure Node.js and npm are installed.

### Installation Steps

1. Clone the repository:

git clone https://github.com/R0la842/SilverNest.git

2. Navigate to the project directory:

cd SilverNest

3. Install dependencies:

npm install

4. Start the development server:

npm run dev

5. Open the local URL displayed in the terminal to access the application.

## Usage Instructions

### Landing Page

Users can explore the platform, learn how SilverNest works, and navigate to different sections.

### Registration and Login

Users can register by selecting their role and completing the required information.

The prototype includes form validation and a simulated email activation process.

### Services

Users can browse available assistance services, search for specific services, filter by category, and view individual service details.

### Volunteer Registration

Volunteers can provide their information and select a document for the vetting process.

### Dashboard

The application includes role-based dashboard interfaces for managing and monitoring relevant activities.

### Additional Pages

Users can access About, Contact, Safety, Privacy Policy, and Terms of Service pages through the footer.

## Additional Configuration

No additional API keys or environment variables are required for the current front-end prototype.
Email activation and volunteer document submission are simulated front-end interactions and do not require external services.
